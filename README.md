**Deep Learning Framework for Automated Pneumonia Detection Using Chest X-ray Images**

**Project Overview:**

PneumoniaDetector is an explainable deep learning framework for automated pneumonia detection using chest X-ray images. It combines deep learning models with Explainable AI and BERT + LLM to provide understandable explanations for model predictions.

**Objectives:**

- Improve pneumonia detection using deep learning.
- Compare CNN, DenseNet-121, EfficientNet and Transformer models.
- Use multiple chest X-ray datasets for better robustness and generalisation.
- Use Grad-CAM to highlight regions influencing predictions.
- Generate simplified explanations using BERT + LLM.
- Develop a React + FastAPI web-based application.

**Datasets:**

- NIH ChestX-ray14
- RSNA Pneumonia Detection Challenge
- VinDr-CXR

**Workflow:**

Chest X-ray → Preprocessing → Feature Extraction → Deep Learning Model → Pneumonia/Normal Prediction → Grad-CAM → BERT + LLM → AI Medical Report
